# خطة تنفيذ تطوير الهوية البصرية والواجهات (Cyber Sapphire & Electric Indigo)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** الارتقاء بالهوية البصرية وألوان واجهات منصة TaskFlow لتطابق المعايير العالمية للمنصات التقنية الرائدة بتدرجات الياقوت الأزرق والنيلي المشع والزجاج المعتم.

**Architecture:** تحديث متزامن للرموز اللونية في Tailwind CSS ومكتبة Ant Design 5، وإعادة بناء الشعار كرمز فيكتور هندسي متدفق، وتطوير أسطح زجاجية تفاعلية للبطاقات وشريط التنقل وقوائم كانبان مع دعم كامل للعربية والانجليزية واختبار شامل عبر Playwright.

**Tech Stack:** Next.js 15, React 19, Tailwind CSS 3, Ant Design 5, Lucide / Ant Design Icons, Playwright Python Test Suite.

**Spec:** [`docs/superpowers/specs/2026-10-18-cyber-sapphire-visual-identity-spec.md`](file:///Users/jalhoom/Desktop/TaskFlow/docs/superpowers/specs/2026-10-18-cyber-sapphire-visual-identity-spec.md)

## Global Constraints

- الالتزام التام باللغة العربية مع خلو مطلق من الرموز التعبيرية في كافة الكود والنصوص والتقارير.
- الحفاظ على سلامة ونقاء شفرة TypeScript واجتياز `npx tsc --noEmit` بصفر أخطاء.
- توافق كامل مع معايير إمكانية الوصول WCAG 2.1 AA بنسبة تباين لا تقل عن 4.5:1.
- الحفاظ على استقرار كلا السيرفرين (المحلي على منفذ 5001 والسحابي) ومبدل البيئات.
- توثيق كافة التغييرات باختبارات آلية وصور ملتقطة عبر Playwright.

## Review Focus

1. تباين ألوان النصوص في الوضعين الداكن والفاتح على خلفيات البطاقات الجديدة.
2. اتساق الهوية البصرية للشعار الجديد في كافة الأحجام (في شريط التنقل، صفحة الهبوط، وصفحات الدخول).
3. انسيابية واستجابة بطاقات لوحة كانبان على أجهزة الجوال والأجهزة اللوحية دون أي قص للنصوص.
4. عدم حدوث أي وميض أو تجميد في الواجهة أثناء التنقل بين الصفحات.
5. التحقق من سلامة كافة أزرار الإجراءات وتأكيد الحذف التفاعلي.
